## P7 — PCIe (ĐẠT)

### 7.1 BAR thật (MEASURED)

```
Region 0: Memory at fa000000 (32-bit, non-prefetchable)  [size=16M]    BAR0
Region 1: Memory at 381000000000 (64-bit, prefetchable)  [size=64G]    BAR1
Region 3: Memory at 380800000000 (64-bit, prefetchable)  [size=32M]    BAR3
Region 5: I/O ports at e000                              [size=128]    BAR5
```

**BAR1 = 64 GB** → **Resizable BAR đã bật và hoạt động**. Đây là kết quả của
DXE ReBAR đã cấu hình ở phiên trước (`BAR1=8GiB` theo ghi chú cũ — nay **64 GB**,
xác nhận ReBAR mở rộng hơn nữa).

### 7.2 Link state — mâu thuẫn có bằng chứng

```
LnkCap:     Port #0, Speed 5GT/s, Width x16
LnkCap2:    Supported Link Speeds: 2.5-5GT/s
LnkCtl2:    Target Link Speed: 5GT/s
LnkSta:     Speed 2.5GT/s (downgraded), Width x16
current:    2.5 GT/s PCIe x16
max:        2.5 GT/s PCIe x16
```

**Phân biệt rõ ba tầng (theo yêu cầu mục 10):**

| Tầng | Giá trị | Nguồn |
|---|---|---|
| **Hardware capability** | 5 GT/s (Gen2) | `LnkCap`, `LnkCap2` |
| **Advertised / target** | 5 GT/s | `LnkCtl2 Target Link Speed` |
| **Runtime state** | **2.5 GT/s (Gen1)** | `LnkSta Speed (downgraded)` |

`max_link_speed` sysfs báo **2.5 GT/s** — đây là trạng thái driver đặt, không
phải giới hạn silicon.

**Kết luận (DECODED):** card **có khả năng Gen2** và **đích được đặt Gen2**,
nhưng **runtime chỉ Gen1**. Nguyên nhân nằm ở link training, không phải strapping
cứng. Log boot có `CMP40_PCIE_GEN2_V2: RETRAIN_FAIL status=1101` — khớp.

**Không thử retrain** (mục 10 cấm).

## P6 — Memory (ĐẠT)

### 6.1 Giải được câu hỏi 8192 vs 7762 MiB

```
Total     : 8192 MiB
Reserved  :  389 MiB
Used      :    0 MiB
Free      : 7804 MiB
BAR1 Total: 65536 MiB   (Used 2 MiB)
```

**Chênh lệch KHÔNG phải 430 MiB như báo cáo cũ, mà là 389 MiB**, và
`nvidia-smi -q -d MEMORY` **nói thẳng đó là "Reserved"**.

### 6.2 Reserved 389 MiB gồm gì — kiểm chứng từng phần

| Nguồn carveout | Kích thước | Bằng chứng |
|---|---:|---|
| WPR2 (GSP) | **0.50 MiB** | MMIO `0x1FA824/28` = `0x01F7E000..0x01FFEE00` |
| Reserved tổng | **389 MiB** | `nvidia-smi -q -d MEMORY` |
| **Còn lại chưa giải** | **~388.5 MiB** | **UNKNOWN** |

**Kết luận (DECODED một phần):** 389 MiB là **carveout dành riêng**, không
phải "VRAM hỏng" hay "ECC". WPR2 chỉ chiếm 0.5 MiB → **388.5 MiB còn lại thuộc
carveout khác chưa xác định**.

Ứng viên (INFERRED, chưa chứng minh):
- Page tables + MMU structures
- PMU/SEC2/FECS/GPCCS code + data vùng
- Compression metadata / ECC parity nếu bật
- VBIOS shadow + devinit scratch

**Không kết luận carveout/ECC khi chưa đo được** (theo mục 9 của đề bài).

## P5 — Topology (ĐẠT MỘT PHẦN)

### 5.1 Dữ liệu xác thực

| Nguồn | Giá trị |
|---|---|
| `fuse+0x650` | `0x0004001F` — popcount **6** (bit 0–4 + bit 18) |
| `fuse+0xC1C` `NV_FUSE_STATUS_OPT_GPC` | `0x00000038` = `0b00111000` — bit 3,4,5 |
| Đo thực tế phiên trước | **17 TPC / 34 SM / 2176 CUDA** |
| `nvidia-smi` | `Max Clocks SM 2100 MHz`, mem 7001 MHz |
| PCI ID | `10DE:1F0B`, subsystem `8804:1043` |

### 5.2 Mâu thuẫn GPC numbering — ghi nhận, chưa giải

`fuse+0xC1C = 0x38` bật **3 bit** (3,4,5). TU106 reference có **3 GPC**.
Nhưng **bit index 3,4,5 không map trực tiếp sang GPC 0,1,2** — cần bitfield
definition không có trong source công khai.

Giả thuyết (INFERRED): `0x38` là **count-encoded** hoặc **mask lệch 3**.
**Chưa đủ bằng chứng để khẳng định.** Giữ trong UNKNOWN `U-FUSE-005`.

### 5.3 Phân loại trạng thái (theo mục 8.D)

| Đơn vị | Trạng thái | Bằng chứng |
|---|---|---|
| TPC/SM | **Present + Enabled** | 17/34 đo được qua CUDA; `fuse+0x650` có dữ liệu |
| ROP | **Present** (chưa đo số) | — |
| L2 | **Present** (chưa đo partition) | — |
| Memory controller | **Present** | GDDR6 7000 MHz chạy được |
| **Display engine** | **Không addressable qua BAR0** | `DISP/SOR/DAC` = `0xBADF1301` |
| **NVDEC** | **Present, không bị fuse khoá** | `NV_FUSE_OPT_NVDEC_DISABLE = 0` |
| NVENC | **Present + Enabled** | đo 73% ở phiên trước |
| Copy engine | Present | — |

**Không tuyên bố display bị cắt vật lý** (mục 8.F). Chỉ ghi: không addressable
qua BAR0, trong khi fuse báo enable.

## P8 — Security (ĐẠT MỘT PHẦN)

### 8.1 WPR regions — đo được

```
NV_PFB_PRI_MMU_WPR2_ADDR_LO = 0x01F7E000  (33,021,952)
NV_PFB_PRI_MMU_WPR2_ADDR_HI = 0x01FFEE00  (33,549,824)
kích thước = 527,872 B = 0.50 MiB
```

**Đối chiếu chéo với log boot:** `WPR=01ffee00:01f7e000` → **khớp chính xác
100%**. Hai nguồn độc lập (MMIO read + dmesg) xác nhận cùng giá trị.

### 8.2 Chuỗi boot từ dmesg thật (bản cmpunlocker đã vá)

```
[4.754] _kgspCreateSignatureMemdesc: signed fullspeed stock-relock WPR-down
        commit FECS=0xfffff...
[4.864] kgspBootstrap_TU102: POST_FWSEC_PRE_GSP_ENTRY
        WPR=01ffee00:01ffe000 FECS=ffffff8f RESET
[4.864] _kgspCmp40ExecuteBooterFreshMeta: fresh WPR metadata
        phys=0x8efde000 signature=0xffe4...
[4.891] kgspExecuteBooterLoad_TU102: FECS_FEATURE_PLM_V140_RESULT
        status=0x0 mailbox0=0x00000000 tracepc=0x00007d11
[4.891] SIGNED_FULLSPEED_STOCK_RELOCK_WPR_DOWN_PASS
[4.891] kgspCmp40RebuildStockSignature: restored stock signature in-place
        phys=0xffe40000
```

**Thứ tự (DECODED):**
1. Tạo memdesc chữ ký (fullspeed stock-relock).
2. Vào `POST_FWSEC_PRE_GSP_ENTRY` — **sau FWSEC, trước GSP**.
3. Ghi WPR metadata mới (`0xFFE40000`).
4. Load booter → FECS feature PLM `status=0x0` (thành công).
5. Khôi phục chữ ký stock tại chỗ.

### 8.3 Trust boundaries (INFERRED, dựa trên bằng chứng)

```
[Host kernel]  -- module verification failed (self-signed, taint kernel)
      |
      |  PCIe MMIO (BAR0 16 MB, BAR1 64 GB)
      v
[GPU SEC2]  -- FWSEC, xác thực trước khi vào GSP
      |         WPR2 = 0x01F7E000..0x01FFEE00
      v
[GSP-RM]    -- RISC-V, chạy trong WPR
      |
      v
[PMU / FECS / GPCCS]
```

**Điểm đáng chú ý (CORROBORATED):** kernel log ghi
`module verification failed: signature and/or required key missing - tainting kernel`.
Driver đang chạy là **bản build lại, chưa ký** — đây là ranh giới tin cậy **đã bị
vượt ở phía host**, không phải phía GPU.

### 8.4 Không làm (theo mục 11 và 15)

- Không tạo payload vượt bảo vệ.
- Không sửa code leo thang đặc quyền.
- Không trích xuất khoá bảo mật.
- Không brute-force.
