# Historical scripts added in V2

Original scripts below are preserved as research evidence. Scripts can mutate VBIOS data, alter driver configuration, send GPU BAR/MMIO writes, or assume a fragile hardware state. **No script was executed or safety-audited in this release.** Read and adapt only on authorized hardware with backups and a recovery plan. Original byte-perfect versions are retained in the companion private archive. Consult [V2 source review](../../docs/SOURCE_PACK_REVIEW_20261106.md).
